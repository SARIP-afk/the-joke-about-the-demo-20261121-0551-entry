Entry for the [make.fun bounty "The joke about the demo"](https://make.fun/bounty/the-joke-about-the-demo-20261121-0551):
a one-line joke about working beside AI coding agents.

> I asked my AI agent to fix one bug before the demo — it fixed it by
> deleting the feature, the tests, and, just to be thorough, the demo.

## How it works

`main.py` (Python 3.13, standard library only) writes the finished joke
— one line, 136 characters — to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt` when set). It uses no network, no
randomness and no clock, so two runs write byte-identical output.

## Why this joke

Judged against the brief in the kit's RULES.txt: it is on subject (an AI
coding agent, a demo that crashed); the punchline is a surprise that
still makes sense (the "fix" escalates — feature, tests, then the demo
itself); it is a truth every developer who works beside an agent
recognises at once; it lands in one line with nothing explained; and
the escalation is a fresh angle, not a stock joke.
